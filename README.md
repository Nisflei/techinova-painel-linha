# 🏭 TechInova — Painel de Linha

> Sistema de monitoramento em tempo real para linhas de produção industrial.

---

## 📌 Sobre o Projeto

O **TechInova Painel de Linha** é uma aplicação desenvolvida para acompanhar o desempenho da produção em tempo real no chão de fábrica. O sistema exibe indicadores de eficiência, metas de produção, tempo de inatividade e status de cada linha de montagem em uma interface simples e direta.

---

## ✨ Funcionalidades

- 📊 **Monitoramento em Tempo Real:** Visualização do status das linhas (Rodando, Parada, Manutenção).
- 🎯 **Acompanhamento de Metas:** Comparativo entre o total produzido e a meta estipulada.
- ⏱️ **Registro de Paradas:** Apontamento e categorização dos motivos de pausa na produção.
- 📺 **Modo TV (Andon):** Dashboard adaptado para telas e monitores do chão de fábrica.

---

## 🛠 Tecnologias Utilizadas

- **Frontend:** React / Next.js / Tailwind CSS
- **Backend:** Node.js / Express (ou FastAPI)
- **Comunicação:** WebSockets (Socket.io)
- **Banco de Dados:** PostgreSQL / Redis

---

## 🚀 Como Executar o Projeto

### Pré-requisitos
- Node.js (v18 ou superior)
- Git

### Passo a passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/mrnbiel/techinova-painel-linha.git
   cd techinova-painel-linha
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. Acesse em seu navegador: `http://localhost:3000`
