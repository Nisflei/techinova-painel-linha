# 📊 Techinova - Painel de Linha (ATUALIZADA PÓS PR)

O **Techinova Painel de Linha** é um sistema de monitoramento e visualização em tempo real voltado para linhas de produção e processos industriais. A aplicação centraliza indicadores de desempenho (KPIs), status operacionais e métricas de eficiência para otimizar o fluxo produtivo e a tomada de decisão.

---

## 🚀 Funcionalidades Principal

- 📈 **Acompanhamento em Tempo Real:** Visualização do status das linhas de produção e métricas operacionais.
- ⏱️ **Monitoramento de Metas e Ciclos:** Medição de eficiência de produção, tempo de ciclo e meta vs. realizado.
- 🚨 **Alertas e Notificações:** Indicação visual e sonora de paradas, gargalos ou desvios de processo (Andon).
- 📊 **Histórico e Relatórios:** Registro de ocorrências e dados para análise posterior.
- 💻 **Interface Responsiva:** Otimizada para displays industriais, TVs e monitores de chão de fábrica.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript / TypeScript *(React / Vue / Angular)*
- **Backend:** Node.js / Python / Java *(se aplicável)*
- **Banco de Dados:** PostgreSQL / MySQL / MongoDB *(se aplicável)*
- **Estilização:** Tailwind CSS / Bootstrap / Styled Components
